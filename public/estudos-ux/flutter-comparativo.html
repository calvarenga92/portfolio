Aspecto 10 · Web

SEO e indexação

Ser encontrado no Google, no Bing e em redes sociais.

Vantagem Web
Web

HTML é a língua nativa dos buscadores. Com renderização no servidor (SSR) ou geração estática (SSG), o conteúdo é indexado com facilidade.

Next.js, Nuxt, Astro e Remix entregam HTML pronto para o robô.
Meta tags, Open Graph e dados estruturados (JSON-LD).
Cada página tem a sua URL, compartilhável e indexável.
Flutter

O Flutter Web desenha num canvas, então não há texto em HTML para o robô ler. A própria equipe do Flutter recomenda usá-lo para apps, e não para sites de conteúdo.

Bom para: dashboards, ferramentas internas e apps atrás de login.
Ruim para: blog, landing page, loja que depende de busca orgânica.
Solução comum: site institucional em HTML e o app Flutter separado.
Veredito

A web vence, e não chega a ser uma disputa.
